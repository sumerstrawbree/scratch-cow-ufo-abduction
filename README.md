# Cow UFO Abduction Mini Game on Scratch
--------------------------

My first Scratch project for the Harvard CS50x course (Week 0's lecture: Problem Set 0)

## About
A short interactive game where the player controls a cow's decisions during an encounter with an alien and a UFO.
The player can either decide for the cow to choose to RUN or STAY when the UFO arrives.

## Scratch Concepts Learned
- Variables
- Conditionals
- Loops
- Broadcast messages
- Custom blocks
- Multiple custom sprites
- User input
